MULTIPLE CHOICE QUESTIONS — 25 MCQs


Q1. What is Data Analytics?

A. Storing data only
B. Collecting and analyzing data to gain insights
C. Deleting data
D. Printing reports

Answer: B


Q2. Which of the following is a real-life application of Data Analytics?

A. Fraud Detection
B. Cooking Food
C. Painting
D. Gardening

Answer: A


Q3. Which type of analytics answers the question "What happened"?

A. Predictive Analytics
B. Prescriptive Analytics
C. Descriptive Analytics
D. Diagnostic Analytics

Answer: C


Q4. Which type of analytics answers the question "Why did it happen"?

A. Descriptive Analytics
B. Diagnostic Analytics
C. Predictive Analytics
D. Prescriptive Analytics

Answer: B


Q5. Which type of analytics predicts future outcomes?

A. Descriptive Analytics
B. Diagnostic Analytics
C. Prescriptive Analytics
D. Predictive Analytics

Answer: D


Q6. Which type of analytics suggests actions to be taken?

A. Descriptive Analytics
B. Diagnostic Analytics
C. Prescriptive Analytics
D. Predictive Analytics

Answer: C


Q7. Which of the following is an example of Structured Data?

A. Video File
B. Database Table

D. Email Message

Answer: B


Q8. Which of the following is Unstructured Data?

A. Excel Spreadsheet
B. SQL Table

D. Database Record

Q9. Which of the following is Semi-structured Data?

A. Word Document
B. Database Table

A. Java Source Object Notation

Q11. XML stands for:

A. Extensible Markup Language
