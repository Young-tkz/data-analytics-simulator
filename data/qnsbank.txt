Q1. What is Data Analytics?

Data Analytics is the process of collecting, organizing, and analyzing data to obtain useful information and support decision-making.


Q2. Define Big Data.

Big Data refers to extremely large and complex datasets that cannot be processed using traditional data processing methods.


Q3. What is Structured Data?

Structured data is data that is organized in rows and columns and stored in databases.

Examples:
- Excel sheets
- SQL databases


Q4. What is Unstructured Data?

Unstructured data is data that does not have a predefined format.

Examples:
- Emails
- Videos
- Images
- Social media posts


Q5. What is Semi-structured Data?

Semi-structured data is a combination of structured and unstructured data.

Examples:
- XML files
- JSON files


Q6. What is Data Cleaning?

Data Cleaning is the process of removing errors, duplicates, and missing values from data.


Q7. What is Normalization?

Normalization is the process of scaling data values between 0 and 1.


Q8. What is Standardization?

Standardization is the process of converting data into a standard format with a mean of 0 and a standard deviation of 1.

SECTION B — SHORT ANSWER QUESTIONS
(3–5 Marks)
==================================================

Q12. Explain the importance of Data Analytics.

- Helps in decision-making.
- Improves business performance.
- Predicts future trends.
- Understands customer behaviour.
- Increases profitability.


Q13. Explain Descriptive Analytics.

Descriptive Analytics studies historical data to understand what happened in the past.

Example:
- Monthly sales reports


Q14. Explain Diagnostic Analytics.

Diagnostic Analytics determines why a particular event happened.

Example:
- Finding the reasons behind declining sales.


Q15. Explain Predictive Analytics.

Predictive Analytics uses statistical techniques and machine learning to predict future outcomes.

Example:
- Predicting customer demand.


Q16. Explain Prescriptive Analytics.

Prescriptive Analytics recommends actions that should be taken based on predictions.

Example:
- Suggesting the best marketing strategy.


Q17. Differentiate between Structured and Unstructured Data.

Structured Data:
- Organized format
- Easy to analyze
- Stored in databases

Unstructured Data:
- No predefined format
- Difficult to analyze
- Includes files such as images, videos and social media content


Q18. Explain Secondary Data Collection.

Secondary Data Collection uses existing data collected by others.

Examples:
- Research papers
- Government reports


Q19. What are Data Sources?

Data sources are places from where data is obtained.

Examples:
- Databases
- Websites
- Sensors
- Social media


Q20. Explain Data Integration.

Data Integration combines data from multiple sources into a single unified system.

Advantages:
- Scalability
- Fault tolerance
- Cost effectiveness

- Real-time processing
