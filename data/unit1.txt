WHAT IS DATA?

Data is a collection of facts, figures, observations, or information that can be used for analysis and decision-making.

Examples:
- Student marks in an examination
- Daily sales of a supermarket
- Number of visitors on a website


FROM DATA TO ANALYTICS

Collecting Data + Studying Data + Better Decisions

Analytics means examining and understanding data to find useful patterns and trends so that better decisions can be made.

WHAT IS DATA ANALYTICS?

Data Analytics is the science of analyzing raw data to draw conclusions and make informed decisions.

It involves:
- Collecting data
- Organizing data
- Cleaning data
- Analyzing data

Goal:
- Discover meaningful information to support decisions
- Understand what happened and why
- Help determine what may happen next and what should be done


WHY IS DATA ANALYTICS IMPORTANT?

- Banks analyze customer transaction data to manage risk.

- E-commerce sites record customer purchases to personalize offers.

SEMI-STRUCTURED DATA

WHAT IS DATA COLLECTION?

Data Collection is the process of gathering information from different sources for analysis and decision-making.

Reasons for collecting data:
- To understand a problem clearly
- To make better, evidence-based decisions

Examples:
- Incorrect attendance records can make a college target the wrong students.
- Supermarkets collect bills, product details and purchase time to find best-sellers.


PRIMARY VS SECONDARY DATA COLLECTION

PRIMARY DATA

Collected directly from the original source.

Methods:
- Surveys
- Interviews
- Questionnaires
- Observation
- Experiments

Examples:
- A college survey asking about study hours
- A hospital survey on patient satisfaction


SECONDARY DATA

Already collected by someone else.

Sources:
- Government reports
- Census data
- Newspapers
- Research papers
- Websites

Examples:
- Using census data instead of conducting a new survey
- Using government population data to plan a new store


METHODS OF PRIMARY DATA COLLECTION

SURVEYS
A list of questions asked to people.
Example: Google Forms survey on satisfaction with online classes.

INTERVIEWS
Information collected by asking questions directly.
Example: Interviewing customers about a new product.

OBSERVATION
Data collected by observing people or situations.
Example: A teacher observing classroom behaviour.

EXPERIMENTS
Data collected by conducting controlled experiments.
Example: Scientists testing a new medicine.

COMMON CHALLENGES IN DATA COLLECTION

MISSING DATA
Some information is not available.
Example: A student's phone number is missing.

INCORRECT DATA
Wrong values are entered.
Example: Age entered as 250 years.

DUPLICATE DATA
The same record is captured more than once.
Example: A customer is registered twice.

OUTDATED DATA
Old information is not refreshed.
Example: An old address is stored in the database.


WHAT IS DATA PREPROCESSING?

Data preprocessing is the process of cleaning and preparing raw data before analysis.

Real-world data is often:
- Incomplete
- Incorrect
- Duplicate
- Inconsistent
- Noisy

Without preprocessing, analysis results may be wrong.


STEPS OF DATA PREPROCESSING

1. DATA CLEANING
Correcting errors and gaps.

2. DATA INTEGRATION
Combining multiple sources.

3. DATA TRANSFORMATION
Converting data into a suitable format.

4. DATA REDUCTION
Simplifying data without losing meaning.

Result:
Prepared data ready for reliable analysis.


DATA CLEANING & HANDLING MISSING VALUES

Data cleaning includes:
- Removing missing values
- Correcting wrong values
- Removing duplicates
- Removing unwanted data

Methods:

1. Remove Records
Delete the incomplete record entirely.

2. Fill with Average
Example:
Marks = 70, 80, NULL, 90
Average of 70, 80 and 90 = 80
The missing value can be filled with 80.

3. Fill with Most Frequent Value
Example:
Blood Group = A, B, A, NULL
Replace NULL with A.


DATA INTEGRATION

Combining data from different sources into one.

Examples:
- Combining a college database with a library database.
- Hospitals integrate patient records, lab reports and pharmacy data.

Benefit:
- Gives one unified, complete view of each record.


DATA TRANSFORMATION

Converting data into a suitable, standard format.

Examples:
- 50000 -> 50,000 INR
- 10-07-2026 -> July 10, 2026

Banks can convert raw transactions into monthly reports.


DATA NORMALIZATION

- Converts data into a common, comparable scale.
- Useful when values are very different in magnitude.
- Machine Learning algorithms perform better on normalized data.
- Prevents one large-scale variable from dominating analysis.


DATA REDUCTION

Reduces data volume without losing key information.

Example:
Instead of storing every seconds temperature:
30, 31, 30, 31
Store the average:
30.3°C

YouTube compresses large user data for faster processing.


REMOVING DUPLICATES

- Keep only one copy of a repeated record.
- Example: A customer registered twice -> keep one entry.
- Prevents double-counting in analysis.


OUTLIER DETECTION

Outliers are unusual or extreme values in the data.

Example:
Marks = 70, 80, 75, 90, 1000
1000 is an outlier.

Banks may flag unusual transactions as possible fraud.


BENEFITS OF DATA PREPROCESSING

- Improves overall data quality and accuracy
- Reduces errors that could mislead analysis
- Saves time during analysis
- Improves decision-making and analytical efficiency
- Produces reliable, trustworthy analysis results

- Missing values
- Impossible entries such as attendance over 100%
- Missing marks

After preprocessing:
- Missing values were filled or corrected
- Invalid entries were fixed
- Data became ready for reliable analysis
